# 三個 Issue 整合說明（開發測試版）

## 修改
- #1：參加者依 ID 設定 0–1000 權重，重複報名保留多個抽取機會；抽取採加權隨機。
- #8：中獎紀錄可勾選已領獎，CSV 含領獎狀態。
- #11：姓名包含搜尋、獎項篩選、清除篩選與無結果提示。
- GAS：新增權重、領獎與中獎紀錄工作表，以及受 ADMIN_TOKEN 保護的寫入端點。

## 部署
1. 在 Google Apps Script 中更新 gas/Code.gs，於「專案設定 > 指令碼屬性」新增 ADMIN_TOKEN，使用高強度隨機字串。
2. 部署新版 Web App，將 /exec 網址填入網頁的 API 設定。
3. 需管理員操作時，輸入權杖（僅保留在當前頁面的輸入框，不存入 localStorage）。
4. 開啟網頁、連線載入資料、測試加權抽獎／領獎勾選／搜尋與 CSV。
5. 寫入後重新載入 API，確認 Google Sheets 中三個工作表已更新。

## 重要限制（正式使用前必讀）
- 此版為可提交審查的整合草案，尚未經實際 GAS 部署與端到端驗證。
- GAS ContentService 跨網域 POST 使用 no-cors；前端只能確認請求已送出，**不能確認後端已成功寫入**。必須重新讀取 API 驗證。
- 前端抽獎仍在各瀏覽器執行；多人同時抽獎可能發生配額競爭，**不可視為具備原子性的一致性抽獎系統**。
- GET 端點公開回傳中獎與領獎資料；若含個資，必須改用受控存取及減少輸出欄位。
- 管理權杖由管理員輸入，請勿寫進公開 GitHub 原始碼、截圖或分享給非授權人員。
- 本機離線展示模式與正式 Sheets 資料不是同一份資料；重新連線後以後端資料為準。
- 原本重置按鈕可刪除正式中獎紀錄，正式上線應另加後端權限與雙重確認。
